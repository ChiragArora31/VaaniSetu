# VaaniSetu Submission

This directory contains the final five-slide hackathon deck. Generate the complete private submission candidate with:

```bash
python scripts/release_evidence.py
python scripts/build_submission_bundle.py
```

The generated ZIP lives under `outputs/` and is intentionally not committed because it contains generated reports and public demo media. It excludes accounts, sessions, BAIF content, model weights, tokens and runtime logs.
