1. BAIF administrator: install and hand over

Before starting

Windows 11, at least 16 GB RAM, six CPU cores and 20 GB free disk are available.
Python 3.10 or 3.11 is installed from python.org with the Python launcher.
Internet is available for controlled setup and approved model downloads.
The authorised team account has accepted the intended IndicTrans2 model terms.
The repository is in a BAIF-approved local folder, not a public sync folder.
BAIF has named the administrator, reviewer and backup owner.

Install once

  1. Open PowerShell in the VaaniSetu folder.
  2. Run .\scripts\setup_baif_worker.ps1. The script selects Python 3.11 or 3.10, creates a local .venv, installs dependencies and prepares models.
  3. Run .\scripts\start_baif_worker.ps1. Leave this PowerShell window open while VaaniSetu is in use.
  4. Open http://127.0.0.1:8501 on the worker. BAIF LAN users should use the approved address supplied by IT.
  5. Create the first administrator with a unique password of at least 10 characters.
  6. Open System. Ready to translate is sufficient for a controlled engineering demo when the shown backend is named honestly. BAIF production handover requires Production ready, a passing command-line preflight and the approved model inventory.

Approve the first trainer

  1. Ask the trainer to choose Request access, enter their own account details and submit.
  2. In the administrator session, open User approvals and choose Approve.
  3. Ask the trainer to sign in. Never share the administrator account for routine translation.

Release acceptance before real BAIF content

  1. Keep the approved BAIF videos outside Git in a local folder such as C:\BAIF-Test-Data\Videos.
  2. Stop the worker so port 8501 is free, then run .\scripts\windows_acceptance.ps1 -VideosPath "C:\BAIF-Test-Data\Videos".
  3. Do not continue unless every check passes and outputs\windows_acceptance\acceptance_summary.json says passed.
  4. Start locally with .\scripts\start_baif_worker.ps1. LAN listening requires the explicit -HostAddress 0.0.0.0 option and BAIF IT approval.
  5. Run 401.1.mp4 first with reviewer-confirmed source language (the technical probe indicates Marathi), Hindi target and subtitles on. Add optional speech/video only after the core package passes.

Two-minute acceptance check

  1. Choose English to Hindi, open Text, enter a short non-confidential agriculture sentence containing a number and unit, then translate.
  2. Confirm the result identifies the local translation route and preserves the number/unit.
  3. Correct and approve the output, download the package, disconnect from VaaniSetu and open CONTENTS.html from the extracted ZIP.

2. Trainer or reviewer: first translation

  1. Open the VaaniSetu address. Choose Request access if you do not yet have an approved account.
  2. Sign in after the administrator confirms approval.
  3. Choose the source language and Translate to language. Source and target must be different.
  4. Choose Record, Text or Upload. For a first run, use a short text sample.
  5. Choose only the outputs needed. Text is always produced; voice and video outputs take longer.
  6. Start translation and leave the page open. Progress and safe cancellation remain visible.
  7. Review the route, warnings, original and translated text. Machine output is a draft.
  8. Edit Corrected translation, inspect the difference, then choose Approve final.
  9. Download the ZIP. Use Reusable library to reopen, rerun or safely delete previous work.
Health, pesticide, financial, safety and legally consequential content always requires an appropriate human reviewer. Do not distribute an unreviewed machine translation as final guidance.

3. Field recipient: use the package offline

  1. Copy the approved ZIP to the field device and extract it.
  2. Open CONTENTS.html. Use its direct links to text, subtitles, audio or video.
  3. No VaaniSetu server or internet connection is required for these exported files.
  4. If any checksum verification fails or the package looks changed, stop and request a fresh approved package.

4. Internal demo: reliable judge path

Before entering the room

The exact release commit, local models and System readiness have been checked.
The public agriculture sample contains no BAIF-confidential content.
The final deck, prepared approved package and fallback walkthrough are available offline.
Browser zoom is 100%, notifications are off and the machine is connected to power.
The demo account is active and the browser is already signed in.
No hosted translator, runtime model download or unlicensed asset is enabled.

5. Fast recovery

What you seeWhat to do
System says Needs setupAdministrator opens System, completes the named local setup action and reruns preflight. Trainers should not diagnose models.
Access requestedAdministrator opens User approvals and approves the named account.
Job failed after restartConfirm System readiness, then use Run again. Completed history remains available.
Low disk warningBack up required packages, preview cleanup, then apply retention cleanup. Do not manually remove authentication or review folders.
Voice/video output missingUse the available text/subtitles, then ask the administrator to check optional speech/media readiness.
Package checksum failsDo not use it. Redownload the approved package and verify again.

6. Handover complete when

A BAIF administrator can start/stop the worker and read System readiness.
A trainer can request access and complete translate, review, approve and download.
A field recipient can open the extracted package without VaaniSetu or internet.
The administrator can back up, restore a test copy and generate a redacted support bundle.
The named Hindi/Marathi reviewers understand approval responsibility.
Owners, release commit, model inventory, machine profile and unresolved limitations are recorded.
