# Support and Knowledge Transfer

BAIF owns first-line operation: user approval, readiness checks, storage/retention, backups, and basic retries. The implementation team handles reproducible application defects and model/setup escalation. Model-quality questions go to the named Hindi/Marathi reviewers; infrastructure/security incidents follow BAIF incident channels.

Knowledge transfer is complete when a BAIF administrator can install on the target machine, approve a trainer, run the three UAT personas, verify an offline package, create/restore a backup on a test copy, and produce a redacted support bundle. Record the operator, date, release commit, machine profile, and unresolved limitations in the release checklist.
